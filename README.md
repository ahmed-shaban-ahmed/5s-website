# فايف إس — Homepage

Static Arabic RTL homepage for 5S (Sand & Soil Stabilization Smart Solutions).

## Preview locally

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Stack

- HTML / CSS / vanilla JS
- Cairo (Google Fonts)
- GitHub Pages (main branch, root)
