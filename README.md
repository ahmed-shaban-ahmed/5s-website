# فايف إس — 5S | حلول ومواد تثبيت الرمال والتربة

الموقع الرسمي لشركة **فايف إس لحلول تثبيت الرمال والتربة**.

🔗 **الموقع المنشور:** https://ahmed-shaban-ahmed.github.io/5s-website/

## الصفحات الحالية
- الرئيسية — `index.html`
- من نحن (قائمة منسدلة): عن الشركة — `about/` · التقنية — `technology/`
- القطاعات — صفحة لكل قطاع تحت `sectors/` (تسعة قطاعات، بدون صفحة تجميعية)
- المشاريع — `projects/` وصفحة تفصيلية لكل مشروع
- تواصل معنا — `contact/`
- صفحات الحلول: [5S ROAD](solutions/5s-road/) · [5S BERM](solutions/5s-berm/) · [5S DUST](solutions/5s-dust/) · [5S SLOPE](solutions/5s-slope/) · [5S WALK](solutions/5s-walk/)

صفحتا **البيانات الفنية** و**المركز الإعلامي** أصبحتا فعّالتين. باقي الصفحات (الأسئلة الشائعة، النسخة الإنجليزية) ستُضاف عند وصول تصميمها، وروابطها ظاهرة وغير قابلة للنقر حتى ذلك الحين.

### البيانات الفنية
- كل بطاقة ملف PDF؛ التحميل مشروط بنموذج (الاسم والبريد والجوال إلزامية، الشركة اختيارية) يُرسل عبر `https://formsubmit.co/ajax/Sales@5s-Tech.Org` ثم يبدأ التحميل. تُحفظ البيانات في `localStorage` (المفتاح `5s-lead-v1`) فلا يظهر النموذج مرة أخرى، وزر «نسيان بياناتي» يمسحها. عند فشل الإرسال لا يبدأ التحميل.
- **مهم:** عند أول إرسال حقيقي يرسل formsubmit رسالة تفعيل إلى Sales@5s-Tech.Org، ويجب تأكيدها قبل أن تصل الطلبات.
- الملف الحقيقي الوحيد حاليًا: بروفايل الشركة (`assets/pdf/5S-Company-Profile-Arabic.pdf`). بطاقات TDS وMSDS لكل منتج أماكن محجوزة؛ لإضافة ملف حقيقي ضعه في `assets/pdf/` وعدّل `pdf_cards()` في المولّد.

### المركز الإعلامي
- ثلاثة تبويبات (فيديوهات، صور، مقالات) قابلة للربط المباشر: `/media/#videos` و`#photos` و`#articles`.
- الفيديوهات الحقيقية من قناة 5S على يوتيوب وتُفتح داخل نافذة (youtube-nocookie)، والصور من مشاريع الموقع، ومقال واحد له صفحة تفصيلية والبقية أماكن محجوزة (`media.py` في المولّد).

## التقنية
موقع ثابت (HTML / CSS / JavaScript) باللغة العربية من اليمين لليسار، بخط Readex Pro، ومنشور عبر GitHub Pages من الفرع `main`.

```
index.html        الصفحة الرئيسية
about/            عن الشركة
technology/       التقنية
sectors/          صفحات القطاعات التسعة
projects/         قائمة المشاريع + صفحة لكل مشروع
contact/          تواصل معنا
technical-data/   البيانات الفنية (ملفات PDF بنموذج تحميل)
media/            المركز الإعلامي + مقالات
solutions/        صفحات المنتجات الخمسة
css/style.css     التنسيقات
js/main.js        التفاعلات (القائمة، التبويبات، السلايدر، العدّادات)
assets/           الشعار وفيديو الواجهة وصور المشاريع وملفات PDF وصور الفيديوهات
```

النصوص بين أقواس مربعة مثل `[شعار عميل]` أو `[اسم المشروع]` أماكن محجوزة بانتظار المحتوى الحقيقي من العميل.
